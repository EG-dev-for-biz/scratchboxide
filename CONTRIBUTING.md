# Contributing to Scratchbox IDE

Scratchbox IDE is built on a modular architecture designed for performance and extensibility.

## How Can I Contribute?

### Reporting Bugs
If you have found a bug, please file an issue with detailed steps to reproduce.

### Reporting Feature Requests
You may file a feature request describing the motivation, use case, and proposed interface.

### Pull Requests
Before starting significant implementation work, please create or comment on an issue to discuss the approach with maintainers.

## Sign your work

Contributions must include a Developer Certificate of Origin (DCO) sign-off in the commit message:

    Signed-off-by: Your Name <your.email@example.com>
