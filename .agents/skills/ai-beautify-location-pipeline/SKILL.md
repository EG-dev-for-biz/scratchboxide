# AI Beautify Location Pipeline & Strict 3D Framing Skill

The **AI Beautify Location Pipeline** transforms 3D tile blockouts and photogrammetric meshes into photorealistic photographs or Stage 2 start frames (`<IMAGE_REF_0>`) for downstream video synthesis (e.g. Google Omni 1.1).

It enforces strict, non-negotiable camera preservation, exact aspect ratios, 6-decimal geodetic precision, and photorealistic material descriptions without inventing non-existent architectural geometry.

---

## 1. The Exact Canonical Prompt Template

All location restyling and beautification prompts **MUST** adhere to the exact canonical template generated by `buildBeautifyPrompt`:

```text
Transform this photorealistic 3D tiles rendering of {locationName} (camera at coordinates {coords}, facing {heading}°) into a photorealistic photograph. Map reference: {earthUrl}. {moodPromptContext}This is a real location — the reference image shows the actual 3D-rendered buildings, streets, and terrain at these exact coordinates. CRITICAL FRAMING RULES — non-negotiable: (1) Output MUST use exactly {aspectRatio} aspect ratio, matching the reference image canvas. (2) Preserve the EXACT same camera angle, pitch, yaw, viewpoint, composition, focal length, and field of view as the reference. (3) Every building, street, and rooftop must stay in the same on-image position — do not pan, zoom, crop, recompose, or change the horizon line. (4) Do not invent or add buildings, landmarks, or features that are not visible in the reference. Add realistic textures, materials, atmospheric haze, natural lighting, and fine architectural detail to make this look like a real photograph taken from this exact vantage point.{subjectDistanceHint}{styleSuffix}
```

### Dynamic Component Rules

1. **`{coords}`**:
   - Geodetic coordinates formatted to 6 decimal places: `${lat.toFixed(6)}, ${lng.toFixed(6)}`.
   - Fallback if omitted: `'0.000000, 0.000000'`.
2. **`{heading}`**:
   - Azimuth heading in degrees rounded to integer: `${Math.round(heading)}°`.
3. **`{earthUrl}`**:
   - High-resolution Google Earth vantage link: `https://earth.google.com/web/@${lat},${lng},...`.
   - Auto-generated if not passed by caller.
4. **`{moodPromptContext}`**:
   - Atmospheric lighting, weather, or time-of-day directives.
   - Cleanly whitespace-padded so words never collide with `This is a real location`.
   - **CRITICAL DIRECTIVE**: Must remain EMPTY (`""`) unless explicitly requested by the user. Never inject unsolicited lighting or atmospheric defaults.
5. **`{subjectDistanceHint}`**:
   - **When distance is available**:
     ```text
      Subject distance: approximately {distance} meters from camera (use this for depth-of-field, focus, and aerial-perspective haze).
     ```
     *(Note the mandatory leading space).*
   - **When distance is omitted / undefined**: Empty string `""`.
6. **`{styleSuffix}`**:
   - **CRITICAL INVARIANT**: Injecting anything more into the prompt should **ONLY** happen in `{styleSuffix}`.
   - **Leave empty (`""`) unless the user explicitly prompts a style**.
   - When the user prompts a style, it is injected verbatim at the end with a leading space.

## 2. Where the template is applied (no tool call needed)

The generating tools apply the template themselves, so the agent does not build the prompt first:

- `survey_beautify_station`, `survey_beautify_to_splats`, `survey_beautify_to_texture`: `BeautifyStationService` builds the prompt from the station record with `buildStationBeautifyPrompt` (coordinates, yaw, pitch, lens fov, standoff, horizon, sun) and sends exactly that text to the image model. Pass only `locationName`, `styleSuffix` and `moodPromptContext`.
- `spatial_ai_render_scene` (a mesh render with no place): `NativeAiRenderEngineService` sends the clay-render variant, `buildClayRenderBeautifyPrompt` (same framing rules, no coordinates, heading or map reference).

The agent tool `build_beautify_prompt` is deprecated and hidden since 2026-10-20 (registered for one release so saved scripts still run); do not name it in new instructions.

## 3. Codebase API Reference

Import from either `location-beautify-service` or the video service barrel:

```typescript
import {
    buildBeautifyPrompt,
    type BeautifyPromptOptions
} from '@scratchbox/core/browser/generative-canvas/services/location-beautify-service';
// Or:
// import { buildBeautifyPrompt } from '@scratchbox/core/browser/generative-canvas/services/video';

const prompt = buildBeautifyPrompt({
    locationName: 'Independence Hall, Philadelphia',
    coords: { lat: 39.9489, lng: -75.1500 },
    heading: 180,
    distance: 120,
    aspectRatio: '16:9',
    styleSuffix: ' Crisp autumn morning, natural atmospheric depth.'
});
```

## 4. 3-Stage Dual Omni Video Pipeline Integration

In the 3-Stage Dual Omni pipeline:
1. **Stage 1**: Stream high-quality 3D tiles blockout video (`<VIDEO_REF_0>`) and isolate Frame 1.
2. **Stage 2**: Beautify Frame 1 with `buildBeautifyPrompt` (or `buildBlockoutNanoBananaPrompt`) into photorealistic `<IMAGE_REF_0>`.
3. **Stage 3**: Prompt Google Omni 1.1 with minimal spatial guidance:
   ```text
   Follow the 6-DoF camera trajectory, depth parallax, vanishing points, and geometric boundaries of <VIDEO_REF_0>.
   ```
   Passing `<IMAGE_REF_0>` as the initial reference image anchor.
