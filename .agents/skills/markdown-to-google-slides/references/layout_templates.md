# Presentation Layout Archetypes (Scratchbox Studio Engine)

Extracted from `/dev/scratchbox-studio/frontend/app/lib/pptx-export.ts` and `markdown-to-slide-ast.ts`.

Every slide in the deck is assigned one of eight mathematically balanced layout archetypes based on its semantic content and visual requirements.

---

## The 8 Slide Archetypes

### 1. `hero-opener`
- **Purpose**: Title deck, opening keynote slide, high-impact emotional hook.
- **Visual Staging**: Full-bleed 16:9 hero image covering the entire slide canvas.
- **Scrim Overlay**: Bottom 45% of the slide carries an alpha gradient scrim (`bottom-to-top`, 85% opacity) generated by the scrim engine.
- **Typography**:
  - Title: Large responsive font (`slideHeightPt * 0.09`, 32–44pt), bold, positioned at bottom 42% (`y: 58%`), bottom-aligned.
  - Subtitle / Logline: 14–18pt, muted brand secondary color, line spacing 1.4×, max 160 characters.
- **Markdown Mapping**: Slide 1 with `# Document Title` and hero photography.

### 2. `section-divider`
- **Purpose**: Act breaks, chapter transitions, category pivots (e.g. `THE APPROACH`, `TONE`, `CINEMATOGRAPHY`).
- **Visual Staging**: Minimalist, high-end editorial void. Zero clutter.
- **Anchor Element**: A crisp brand accent bar (`w: 8% of slide width`, `h: 0.05 inches`) positioned at `y: 35%`.
- **Typography**:
  - Section Title: Uppercase tracked text (`charSpacing: 3`, 28–36pt), bold, starting directly beneath the accent bar.
  - Subtitle / Synopsis: Optional single paragraph (under 120 words) explaining the chapter premise.
- **Markdown Mapping**: Any slide with an `## H2` or `### H3` header and brief prose (< 150 words) with no images.

### 3. `image-forward`
- **Purpose**: Core visual narrative slide. Focuses the viewer on a primary visual concept while providing concise explanatory context.
- **Visual Staging**: Asymmetric side-by-side split.
  - **Left Column (Text Box - 35% width)**:
    - Section title with horizontal accent bar anchor (`accentBarWidthIn`, `accentBarHeightIn`).
    - Body copy / bullet points formatted with comfortable 1.5× line spacing.
  - **Right Column (Media Box - 62% width)**:
    - Dominant single image fitted precisely via `computeFitDimensions` preserving its natural aspect ratio.
- **Markdown Mapping**: Sections containing 1 image accompanied by 1 to 3 paragraphs or bullet points.

### 4. `text-left-images-right`
- **Purpose**: Multi-perspective visual proof, character sheets, location surveys, or before/after comparisons.
- **Visual Staging**:
  - **Left Column (Text - 38% width)**:
    - Anchored by a 3pt brand-accent vertical line along the left margin.
    - Title + detailed breakdown / narrative copy.
  - **Right Column (Image Grid - 58% width)**:
    - Automatically structures 2 to 4 companion images into a clean 1×2 column or 2×2 grid with uniform 8pt gutters.
- **Markdown Mapping**: Sections containing 2 to 4 images paired with descriptive body copy or structured bullets.

### 5. `curated-grid`
- **Purpose**: Moodboards, texture galleries, storyboard shot progressions, or visual research spreads.
- **Visual Staging**: Full-canvas balanced grid (1×2, 2×1, or 2×2) with uniform outer padding (`paddingIn`) and inner gutters.
- **Captions / Codes**: Optional floating pill overlays displaying shot codes (e.g., `SHOT 01A`, `EXT. NIGHT`).
- **Markdown Mapping**: Slides containing 2 to 4 images with minimal or zero body text.

### 6. `script-page`
- **Purpose**: Screenplay excerpts, customer interview transcripts, dialogue beats, or detailed narrative copy.
- **Visual Staging**:
  - Left vertical brand accent line (`ptToInches(3)`) running the full height of the text block.
  - Monospace or clean editorial serif/sans styling for sluglines (`INT. / EXT.`), character cues (`ALL CAPS`), parentheticals (`italic`), and dialogue.
- **Markdown Mapping**: Screenplay blocks, interview transcripts, or dense narrative prose (> 300 words).

### 7. `composite`
- **Purpose**: Data slides, comparison tables, multi-metric performance readouts, structured deliverables.
- **Visual Staging**: Clean multi-column split or structured table presentation.
  - Table headers filled with `secondaryAccent` brand tone.
  - Thin 0.5pt solid borders.
  - Numeric alignment and bold primary keys.
- **Markdown Mapping**: Markdown tables (`| Col 1 | Col 2 |`), nested bullet lists, or metrics cards.

### 8. `full-bleed-text-overlay`
- **Purpose**: Immersive cinematic beat, closing quote, single-minded proposition (SMP).
- **Visual Staging**: Full-bleed photographic frame with a subtle gradient scrim and centered or lower-third punchy quote text.
- **Markdown Mapping**: Blockquotes (`> Quote`) over high-impact hero photography.

### 9. `art-card` (Power Title / Commandment Interstitial)
- **Purpose**: Thesis statements, bold commandments, single-minded axioms (e.g. `GOOD DECKS SELL IDEAS.`, `OPEN STRONG`, `VS.`).
- **Visual Staging**: Full obsidian negative space void.
- **Typography**: Ultra-condensed heavy display font (48–72pt), centered, ALL CAPS, tight optical kerning, optional horizontal underline bar beneath active term.
- **Markdown Mapping**: Slides containing only a single heading (`#` or `##`) with zero body text or under 10 words.

### 10. `anamorphic-letterbox`
- **Purpose**: Cinematic scene direction, atmospheric keyframe statements, filmic pull quotes.
- **Visual Staging**: 2.39:1 horizontal cinematic image band centered inside the 16:9 canvas with deep black letterbox bands top and bottom.
- **Typography**: Tracked uppercase white text (13–15pt, `charSpacing: 3`) centered across the image viewport with subtle gradient scrim.
- **Markdown Mapping**: Single blockquotes (`> text`) paired with a single widescreen image.

### 11. `script-page-2up-stacked`
- **Purpose**: Screenplay beats, commercial dialogue breakdowns (:30 / :60), script-to-visual mapping.
- **Visual Staging**:
  - Left Column (58%): 2-column screenplay text flow with bold uppercase speaker tags (`HERO:`, `CLARICE:`).
  - Right Column (38%): 2 stacked widescreen keyframe still frames.
  - Footer: Campaign and agency metadata (`SUPER BOWL 2020 | VENABLES BELL & PARTNERS`).
- **Markdown Mapping**: Screenplay formatted text paired with exactly 2 images.

### 12. `recap-card-grid`
- **Purpose**: Rule summaries, deck commandments, executive synthesis, key takeaways.
- **Visual Staging**: Symmetrical grid of clean, solid white container cards (e.g. 2×4 or 2×5) on the dark obsidian canvas with bold uppercase centered bullet copy.
- **Markdown Mapping**: Slides containing a numbered list of 6–10 short points (< 10 words each).

## Automated Classification Rule Tree

When processing a slide from AST tokens:

```typescript
function classifyTemplate(slide: ParsedSlide, index: number, total: number): SlideTemplate {
  const isFirst = index === 0;
  const hasImages = slide.images.length > 0;
  const imageCount = slide.images.length;
  const hasTable = slide.bodyBlocks.some(b => b.type === 'table');
  const bodyLength = getBodyWordCount(slide);
  const isNumberedList = slide.bullets.length >= 6 && slide.bullets.every(b => b.length < 50);

  if (isFirst && hasImages) return 'hero-opener';
  if (hasTable) return 'composite';
  if (!hasImages && !slide.body && !slide.bullets.length && slide.title) return 'art-card';
  if (!hasImages && isNumberedList) return 'recap-card-grid';
  if (!hasImages && bodyLength < 40) return 'section-divider';
  if (!hasImages && bodyLength >= 150) return 'script-page';
  if (hasImages && imageCount === 2 && bodyLength >= 60) return 'script-page-2up-stacked';
  if (hasImages && imageCount === 1 && slide.bodyBlocks.some(b => b.type === 'blockquote')) return 'anamorphic-letterbox';
  if (hasImages && imageCount === 1 && bodyLength <= 80) return 'image-forward';
  if (hasImages && imageCount >= 2 && bodyLength <= 20) return 'curated-grid';
  if (hasImages && imageCount >= 2 && bodyLength > 20) return 'text-left-images-right';
  if (slide.bodyBlocks.some(b => b.type === 'blockquote') && hasImages) return 'full-bleed-text-overlay';

  return 'composite';
}
```
