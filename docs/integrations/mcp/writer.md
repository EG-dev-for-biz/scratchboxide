### `writer_export_presentation`

Export the authored deck from the named Presentation node to PPTX, or create a Google Slides presentation in the user's connected Google Drive. Google Slides delivery requires an idempotencyKey and returns a durable deliveryJobId; call writer.google_slides_delivery_status to retrieve its final status and verified external presentation ID/URL.

| Parameter | Type | Required | Notes |
|---|---|---|---|
| `format` | enum("google-slides" \| "pptx") | no | "pptx" for a PowerPoint download. "google-slides" creates a new Slides presentation in the connected account. Default: pptx. |
| `idempotencyKey` | string | no | Required for Google Slides. Reuse only to retry the exact same delivery request. _(minLength 1, maxLength 200)_ |
| `nodeId` | string | no | ID of the existing Presentation node whose authored deck to export. Required for headless PPTX export. _(minLength 1)_ |
