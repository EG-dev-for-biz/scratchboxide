### `frame_run_children`

Start a durable Basic frame run over a bounded set of direct children. Only explicitly whitelisted, workspace-guarded Basic durable tasks are accepted (toolName enum covers storyboard frames, Prompt Studio image/video, transcription, restyle-with-preset, character ref views/sheets/3D/voiceover, deep write, presentation media/deck, location imagery/scout, image restyle/upscale/edit/reimagine/remove-object/animate/compose, illustration interpret, and audio sfx/lyrics/extend/edit/restyle/scorebox/dialogue/podcast). Each child is independently bound to its exact node, idempotent, spend-capped, persisted, cancellable, and polled to a terminal state.
