### `prompt_studio_run_saved_recipe`

Execute a supported saved Prompt Studio Image Generator recipe using persisted node mode. Image recipes queue 1–4 independent durable Nano Banana Pro jobs and accept authorized workspace-stored image references from persisted node refs, connected image cards, and promoted image @mentions. Video recipes run through guarded Gemini Omni on the Vertex AI Interactions API with the same reference sources; 3–10 second clips and 16:9 or 9:16 ratios are supported. Browser-local files, masks, URL-only inputs, and non-image connected context are rejected. Poll operation.get or request operation.cancel for the returned operationId. This does not execute legacy agentRecipes.
