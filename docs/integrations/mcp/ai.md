### `ai_generate_images`

Queue 1–4 billed Nano Banana Pro images in the active workspace. Use prompts for different prompt variants or count for independent samples of one prompt. Alternatively provide recipeTheme to generate and use distinct Prompt Studio prompt recipes. Each output is a separate durable job and canvas image. Requires a unique idempotencyKey. (Auto-polls completion on scratchbox.ai and returns the direct public CDN image URL).

| Parameter | Type | Required | Notes |
|---|---|---|---|
| `aspectRatio` | enum("1:1" \| "16:9" \| "9:16" \| "4:3" \| "3:4" \| "2:3" \| "3:2" \| "21:9" \| "4:5" \| "5:4") | no |  |
| `count` | integer | no | Number of independent images for prompt; each is billed separately. _(min 1, max 4)_ |
| `idempotencyKey` | string | yes | Stable caller-generated key reused only when retrying this exact generation request. _(minLength 1, maxLength 190)_ |
| `maxEstimatedCost` | integer | no | Optional per-image maximum credit estimate; every image is checked independently before its job is queued. _(min 0)_ |
| `prompt` | string | no | _(minLength 1)_ |
| `prompts` | array<string> | no | One prompt per requested recipe/image. When supplied, count is not allowed. _(minItems 1, maxItems 4)_ |
| `recipeCount` | integer | no | Number of distinct recipe prompts to generate; defaults to 3. Only valid with recipeTheme. _(min 2, max 4)_ |
| `recipeTheme` | string | no | Generate distinct Prompt Studio prompt recipes for this visual theme, then queue one image per recipe. Mutually exclusive with prompt, prompts, and count. _(minLength 1, maxLength 1000)_ |
| `targetFrameId` | string | no |  |
| `targetFrameName` | string | no |  |
| `waitForCompletion` | boolean | no | Whether to wait for image generation to complete and return the public URL (default true). |
