### `character_generate_voiceover`

Generate a short voice-over using a configured Google prebuilt voice. A Basic Spoken Audio source node and billed durable synthesis job are persisted before generation; completed audio is saved to workspace storage and the canvas. Requires a writable workspace and stable idempotencyKey. Maximum 500 characters.
