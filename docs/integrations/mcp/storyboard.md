### `storyboard_export_timeline`

Export one persisted Storyboard section timeline as individual clips or clips plus an FCPXML timeline. Uses existing stored assets and the FFmpeg-aware ZIP export pipeline, stores the ZIP in the active workspace, and reports only a complete byte-verified result. Missing clip assets fail the entire export; no partial ZIP is claimed.

| Parameter | Type | Required | Notes |
|---|---|---|---|
| `editorial` | boolean | no | Set true to include an FCPXML timeline alongside the individual clips. |
| `nodeId` | string | yes | _(minLength 1)_ |
| `sectionId` | string | yes | _(minLength 1, maxLength 200)_ |

### `storyboard_to_presentation`

Create a native editable Presentation node with one slide per storyboard shot, using authorized stored stills when available and preserving prompts as speaker notes. No images are generated.
