### `workspace_switch`

Mark a workspace id as active for the remainder of this MCP session. The new id is returned and applied to subsequent canvas tool calls. The stdio transport persists this for the process lifetime; the HTTP transport requires the client to re-send `x-scratchbox-workspace-id` to make it stick across reconnects.

| Parameter | Type | Required | Notes |
|---|---|---|---|
| `workspaceId` | integer | yes | Target workspace id |
