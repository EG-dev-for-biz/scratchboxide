### `location_imagery`

Queue one billed, durable scouting image for an existing Basic Location using an actual Google Maps Street View Static API source at the node's saved coordinates. Requires verified outdoor coverage, a workspace/canvas write scope, and an idempotencyKey. Output is explicitly an AI rendering grounded in and cited to that real source.

| Parameter | Type | Required | Notes |
|---|---|---|---|
| `heading` | integer | no | Google Street View camera heading in degrees. Defaults to 0. _(min 0, max 359)_ |
| `idempotencyKey` | string | yes | _(minLength 1, maxLength 160)_ |
| `maxEstimatedCost` | integer | no | _(min 0)_ |
| `nodeId` | string | yes | _(minLength 1)_ |
| `prompt` | string | no | Optional rendering direction. The worker still supplies the verified Street View source and requires the result to preserve its real place. _(minLength 1, maxLength 1500)_ |
